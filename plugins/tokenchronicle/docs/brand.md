# TokenChronicle 词元日志 · Brand

## 标识 / Identity

时间环代表持续留存的每日记录；中央的日志横线与 T 字母代表 TokenChronicle；蓝色词元代表新加入的记录。
The time ring represents continuity, the journal/T mark represents TokenChronicle, and the blue token represents a new entry.

- 主色 / Primary: teal `#0F766E`.
- 强调色 / Accent: blue `#2563EB`.
- `assets/logo.png`: 1024 x 1024 PNG, plugin detail logo, light and dark mode.
- `assets/icon.png`: 128 x 128 PNG, composer and compact display.
- 图标使用不透明背景，兼顾深浅主题；不要拉伸、改色或添加其他平台标志。
- Use the opaque-background mark on either theme; do not stretch, recolor, or combine it with other platform marks.

资源在开发仓库的 `plugin/tokenchronicle/assets/` 中，公开插件包的 `assets/` 中。
Development assets live under `plugin/tokenchronicle/assets/`; installed assets live under `assets/`.

## 生成与发布 / Creation and Release

Created with the built-in image generation tool, then resized with macOS `sips`. The selected design brief: a flat teal square containing a white segmented chronological ring, a central journal/T mark, and one blue token; no wordmark, mockup, glow, or external brand symbol. The final PNGs are the release masters, so rebuilding does not call an image model.
