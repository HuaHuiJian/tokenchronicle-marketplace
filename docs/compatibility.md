# Compatibility

The planned client supports Python 3.9-3.13 and local Codex state. Archive, reports, and the loopback
viewer are cross-platform; local scheduling uses launchd on macOS and Task Scheduler on Windows.
Encrypted iCloud snapshots are macOS-only. See the release evidence attached to each published version.

The catalog intentionally remains empty until signed macOS and Windows clients pass clean-host tests.
